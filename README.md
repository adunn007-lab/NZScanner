## Legal/source boundary
The project contains placeholder URLs only. Replace them with public streams you are authorized to redistribute. It intentionally does not include encrypted Police communications, keys, interception or decryption functionality.

NZ Police describes its Public Safety Network as a secure digital communications network, and its SDRN documentation describes secure communications. See:
https://www.police.govt.nz/about-us/publication/third-party-access-secure-digital-radio-network-police-manual-chapter
